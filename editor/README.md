# Редактор квиза

Запуск:

```powershell
npm run editor
```

Откройте `http://127.0.0.1:8091/editor/`.

Вкладка «Квиз» меняет тему и добавляет пустые раунды. Вкладка «Слайд» даёт
выбрать существующую секцию, применить шаблон вопроса или ответа, добавить
атрибуты, выбрать уже загруженный файл из `media/` и отредактировать HTML.
«Исходник» показывает весь `index.html`, поэтому в нём можно делать любые
уникальные слайды и менять структуру вручную.

Изменения существуют в памяти, пока не нажата «Сохранить». При сохранении
сервер создаёт `index.html.bak-YYYYMMDDTHHMMSSZ` рядом с `index.html`, затем
заменяет сам файл. Для отката остановите сервер и скопируйте нужный backup
поверх `index.html`.

Редактор запускается только на `127.0.0.1`, никогда не загружает и не меняет
файлы в `media/`. Если вручную удалить `quiz-editor`-маркеры в исходнике,
полный HTML всё ещё можно сохранить, но структурированные инструменты не
смогут надёжно найти соответствующую область.
